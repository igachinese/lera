# Мост к HSK2 — Лера

Сайт-конспект на 3 недели после HSK1: 6 уроков по 60 минут
(复习 → 新课 → 练习 → 会话 → 作业), режим «Учитель / Экран ученика»,
таймер блоков, карточки слов и интерактивные задания в блоке «Отработка»:
выбор в пропуск, сборка фраз, перетаскивание слов в пропуски и по корзинам,
«верно / ошибка», пары, бинго, устные задания с ответом.

Ещё: озвучка китайских слов и фраз (голос браузера), тренажёр карточек
«знаю / ещё раз», звёзды за выполненные задания с конфетти, запись своего
голоса в блоке «Разговор». Оформление — яркая пастельная палитра, есть тёмная тема.

Статический сайт без сборки — открывается прямо из `index.html`.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Каркас страницы |
| `lessons.js` | **Весь контент уроков** — править тексты, слова и задания здесь |
| `exercises.js` | **Задания блока «Отработка»** — типы и формат описаны в начале файла |
| `drills.js` | Движок заданий: отрисовка, нажатия, перетаскивание |
| `app.js` | Логика: вкладки, карточки, таймер, режимы |
| `style.css` | Оформление (светлая и тёмная тема) |

## Публикация (GitHub Pages)

1. Смёрджить изменения в `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` опубликует сайт при каждом пуше в `main`.
   Адрес будет вида `https://<пользователь>.github.io/lera/`.

## Локально

Просто открыть `index.html` в браузере или запустить `python3 -m http.server`
и зайти на http://localhost:8000.
